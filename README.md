# 신약 후보물질 독성 예측 (Drug Toxicity Prediction)

분자 구조(SMILES)로 화합물의 **독성 유무**를 예측하는 이진 분류 프로젝트입니다.
EDA에서 얻은 도메인 인사이트를 피처로 연결하고, 가설 → 실험 → 검증을 반복하며 모델을 개선했습니다.

> **결과**: 리더보드 F1 **0.8308 → 0.8386** (라벨 1 기준 F1, 제출 4회)

## 핵심 요약

1. **EDA → 피처 연결**: "지용성은 높고 극성은 낮은 분자가 독성이 많다"는 EDA 결과(문헌의 3/75 규칙과 일치)를 TPSA 피처로 구현했습니다. 두 모델에서 교차검증 5회 중 5회, 4회 개선됐습니다.
2. **평가 지표 착오 발견**: 리더보드 점수로 혼동행렬을 역산해, 채점 기준이 라벨 0이 아니라 **라벨 1 F1**임을 확인했습니다. 잘못된 기준으로 계속 최적화했다면 점수가 약 0.02 떨어졌을 것입니다.
3. **앙상블 다양성 확보**: 트리 모델 4종은 예측 상관이 0.9 이상이라 섞어도 효과가 작았습니다. 판단 방식이 다른 **유사도 기반 SVM**(Tanimoto, MinMax)을 추가해 가장 크게 개선했습니다.
4. **"운으로 좋아 보이는 결과" 걸러내기**: 아래 세 조건을 모두 만족할 때만 제출본을 교체했고, Nested 검증도 함께 사용했습니다. 최종 선택 근거(Hold-out) 순위가 실제 리더보드 순위와 일치했습니다.
   - CV 평균 상승
   - 5-fold 중 4개 이상에서 승리
   - Hold-out 점수 유지 이상

## 데이터

| 파일 | 내용 |
|---|---|
| `train.csv` | 8,349개 분자 · 3,078열 (SMILES, 지문 ECFP/FCFP/PTFP 각 1,024비트, 물성 4개, label) |
| `predict_input.csv` | 927개 분자 (정답 없음, 제출용) |

- label: **1 = 독성 없음 (Positive)**, 0 = 독성 있음
- 평가지표: 라벨 1 기준 F1-score

> ⚠️ **데이터는 강의 제공 자료라 이 저장소에 포함하지 않았습니다.** 실행하려면 위 파일을 프로젝트 루트에 두어야 합니다.

## 접근 방법

| 단계 | 내용 |
|---|---|
| 피처 | 입체 정보를 포함한 Morgan 지문(ECFPC/FCFPC, Count 버전) + PTFP(값이 변하지 않는 열 제거) + 물성 4개 + **TPSA 파생 피처 3개** |
| 모델 | RF · XGBoost · LightGBM · CatBoost (soft Voting) + **Tanimoto / MinMax 커널 SVM** |
| 튜닝 | Optuna (TPE, Bayesian Optimization) |
| 검증 | 공통 평가 함수 (stratified 분할, Pipeline, 5-fold CV, classification report), Hold-out 20%, Nested 선택 |

## 제출 결과

| 제출 | 구성 | CV F1 | Hold-out F1 | 리더보드 F1 |
|---|---|---|---|---|
| 1차 | 트리 4종 Voting + 입체 지문 + TPSA | 0.8274 | 0.8182 | 0.8308 |
| 2차 | 1차 + Count 지문 + SVM(Tanimoto) | 0.8325 | 0.8200 | 0.8373 |
| **3차** | 2차의 SVM을 MinMax로 강화 + seed 평균 | 0.8304 | **0.8217** | **0.8386** |
| 4차 | 2차 + kNN + threshold 조정 | **0.8338** | 0.8153 | 0.8369 |

CV 1위(4차)는 실제로 3위였습니다. 여러 버전 중에서 고를수록 CV 점수가 부풀려진다는 것을 리더보드로 확인했습니다.

## 시도했지만 효과가 없던 것 (기록)

- RDKit 분자 기술자 187개, MACCS, 독성 구조 경고, SMILES 표준화 → 기존 피처와 정보가 겹침
- 이웃 라벨 피처(가장 비슷한 분자들의 독성 여부) → 트리가 이 피처에만 의존해 오히려 하락
- 라벨 1 기준 재튜닝, seed 평균 → 효과 없음

서로 다른 여러 접근이 모두 CV F1 0.82~0.83에서 멈췄습니다. 성능의 상한은 데이터 자체에 있다고 판단했습니다. 거의 같은 구조의 분자끼리도 18%는 라벨이 다릅니다(activity cliff).

## 파일 구성

```
├── EDA_분석.ipynb            # 데이터 품질 · 단변량 탐색
├── 이변량_분석.ipynb          # 물성·지문 ↔ 독성 관계
├── 다변량_분석_참고.ipynb      # 물성 조합별 독성 비율
├── 모델링.ipynb              # 평가 함수, 실험 E1~E6, 개선 실험 9-1~9-12, 제출 파일 생성
├── EDA_그래프/ · 이변량_그래프/ · 모델링_그래프/
└── requirements.txt
```

## 실행

```bash
pip install -r requirements.txt
```

데이터 파일을 루트에 둔 뒤 `모델링.ipynb`를 위에서부터 실행하면 됩니다. Optuna 탐색 기록은 `optuna_tuning.db`에 저장되어 다시 실행하면 이어서 탐색합니다.
